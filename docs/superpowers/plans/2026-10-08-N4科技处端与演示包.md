### Task 24: 审批后端(HxAuditService:通过/退回/预检/重交/三流程副作用)

**Files:**
- Create: `sc_backend/src/main/java/com/fz/scitech/hx/HxAuditService.java`、`sc_backend/src/main/java/com/fz/scitech/hx/HxAdminController.java`
- Modify: `sc_backend/src/main/java/com/fz/scitech/platform/template/PdfRenderService.java`(finalVersion stem 分 tplType,约 3 行)
- Test: `scripts/test_hx_audit.py`

**Interfaces:**
- Produces:
  - `GET /hx/audit?flowType=&status=`(admin 审批列表:flow+project+leader+dept+submitTime 聚合)
  - `POST /hx/{flowId}/review`(admin 通过:登记/变更/验收各自副作用;验收 body 带 verifiedAmount 必填)
  - `POST /hx/{flowId}/reject`(admin 退回:status 1/2 均可,意见必填;status=1 退回视为预检,record.opinion 前缀「盖章前预检」由前端传)
  - `POST /hx/{flowId}/resubmit`(教师:4→1,重新渲染,旧待签+旧扫描件作废)
  - `HxAuditService.approveRegister/Change/Acceptance(uid,username,flow)` 副作用私有方法(编号/改写/结题/终版两张/通知)
- Consumes: HxService 既有守卫(反射不可用则把 guardDraft/guardStatus/transit 改 public 或挪包内工具——**裁定:transit 已包级可见,HxAuditService 同包直接用**)

**关键行为(spec §3.3):**
- 登记:主表 kind=2、audit_status=2、status='立项'、approval_no=HX{年}-{序}(序=当年既有数+1,查 max(approval_no like 'HX{yyyy}-%'),冲突靠 uk_approval_no 兜底重试一次)、declare_date 已有;扩展表 hx_register_date=确认日;通知教师
- 变更:按 change_type 改写(contract_amount→new_amount/end_date→new_end_date/负责人→主表 apply_user_id+leader_name 按 new_leader_id 查 sys_user);改写前后值已有 before_json(submit 时拍,camelCase);通知
- 验收:主表 status='结题'+finish_date=确认日;verified_amount 入扩展表;**终版两张渲染**(hx_acceptance+hx_report,finalVersion=true,biz_type=hx_final_docx/hx_final_report_docx——stem 分 tplType);通知
- review/reject 前置:flow.status=2(或 reject 允许 1/2);transit 条件迁移 2→3 / 1|2→4;record:verify/approve/reject(含 precheck_reject 动作值当 opinion 带预检标注时)
- resubmit:教师入口,status=4→transit 4→1→renderDeliverables+invalidateOld(含 hx_scan)+ACT_RESUBMIT record

**Steps:** 写 test_hx_audit.py 先红(用例:①列表 ②登记通过→台账/编号唯一格式/通知 ③变更通过→字段改写+before 对照 ④验收通过→结题+终版两张 biz_type 断言 ⑤退回(1 预检/2 常规)→教师 resubmit→旧件作废含扫描件 ⑥教师不可调 admin 接口/viewer 拒 ⑦重复通过幂等拒)→ 实现 → 起后端全绿 → JUnit 23/23 回归 → commit `Task 24 审批后端:通过副作用(编号/改写/结题终版两张)+退回预检+重交作废`
